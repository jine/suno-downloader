Download Music from Suno AI

A powerful CLI tool to download playlists, albums, and individual tracks from Suno with metadata preservation and beautiful terminal output.

Get Started View on GitHub
node dist/index.js "https://suno.com/playlist/abc123" -i

Features

🎵

Individual Tracks

Download single songs from Suno with full metadata preservation including titles and artwork.

📋

Full Playlists

Download entire playlists with one command. Files are automatically numbered for proper sorting.

🖼️

Cover Art

Optional cover image downloads to keep your music library visually organized.

✨

Beautiful CLI

Enjoy colorful output with progress spinners and clear status messages powered by Chalk and Ora.

🔧

TypeScript

Built with TypeScript for type safety and excellent developer experience.

📁

Organized Output

Files are saved with numbered prefixes and sanitized filenames for easy management.

Installation

1

Clone the Repository

git clone https://github.com/jine/suno-downloader.git
cd suno-downloader
2

Install Dependencies

npm install
3

Build the Project

npx tsc

Prerequisites

  • Node.js 18 or higher
  • npm or yarn package manager

Usage

Basic Usage

node dist/index.js

Options

Option Description Default
-o, --output Output directory for downloaded files ./downloads
-i, --images Download cover images as well false
-V, --version Output the version number -
-h, --help Display help for command -

Examples

Download a playlist

node dist/index.js "https://suno.com/playlist/abc123"

Download to custom directory

node dist/index.js "https://suno.com/@username" -o ./my-music

Download with cover images

node dist/index.js "https://suno.com/song/xyz789" -i

Output Structure

Files are organized in numbered format with sanitized filenames:

downloads/
└── Playlist_Name/
    ├── 01_Song_Title.mp3
    ├── 01_Song_Title_cover.jpg
    ├── 02_Another_Song.mp3
    └── 02_Another_Song_cover.jpg
